# 新增局部解释质控修订草案 v3

本文件是待确认的实验协议修订，不是已生效的准入规则。触发背景是用户询问新增解释的全量逐条审核是否必要。助手建议取消全量审核训练前置条件，但用户尚未明确采纳该建议。

现行 `STREAMING_EXPLANATION_REVIEWS_ZH.md` 要求：“全生成且所有可用输出实际审核完成后，才生成 `reviews_ready_v1.json`”。仅凭本草案不能创建该文件，也不能把未经阅读的解释写成数学接受。

## 拟采用的规则

1. 对全部 17932 次固定解释生成执行统一自动检查：原始记录与输出哈希、请求边界重放、正常结束、32–64 student tokens、无答案标记、没有可见上下文以外的新数字字面量、一至两句，以及插入后的完整训练上下文不超过 4096 tokens（包括 EOS，不截断）。数字和格式检查不能证明数学正确，也不能检出全部语义泄漏。
2. 已保存的 2724 条实际判断和原始负例完整保留。已实际拒绝的 430 条解释继续排除；不会把它们改成接受。已有接受也仍需通过全部自动检查。判断依据是解释，不删除或更换任何训练根题。
3. 其余 8289 条不再要求逐条实际阅读。通过自动检查的记录只能称为自动可用，必须记录 `all_text_read=false`、`semantic_correctness_verified=false`，不得伪造 `assistant_mathematical_review` 或把语义检查布尔值填为真。生成记录中的原始文本保留。
4. 从全部 10997 条原机械可用解释中，按 candidate ID 排序后使用独立的 `random.Random(42).sample(..., 128)` 冻结 128 条描述性质量样本。该样本与原教师质量抽检、迁移 128 根题名单分别独立。抽样不读取或筛选已有接受/拒绝结果，不在抽检后换题、改 seed 或追加样本。完全相同提示与输出的既有实际判断可核验复用，其余必须实际阅读。
5. 样本报告描述原机械可用总体的问题比例；无需样本全部正确。样本中的实际拒绝按同一“已有实际拒绝排除”规则处理，不依据总体错误比例改阈值、重试生成或选择性修复。样本不是独立人工审核。此前 2724 条按生成顺序开展的审核不是随机误差率估计。
6. 样本报告和自动准入决定分别存储，使用新的 v3 文件名与 provenance，之后适配材料/训练入口。不得用旧 `full_text_reviews.json`、`actual_review_export_v1.json` 或 `reviews_ready_v1.json` 冒充新模式全量审核完成。
7. G2/G3 相同位置和类型共用同一文本及准入决定；无合格解释时回退普通 CoT。NLL 独有位置不能进入 G4 joint 池。7179 根题及已冻迁移 128 名单不变。G4 有限候选与 Vsel/Vaudit 的实际核验、开发网格与公开 test 前冻结规则继续保留。

## 生效条件与范围

用户确认采用该草案后，实施并验证新的自动准入/抽检导出及下游适配，完成固定样本实际报告，再构建 G1–G3 材料并推进正式训练。不能仅修改队列 requires 或制造旧审核完成文件来解除等待。

本次草案准备不启动 GPU，不使用公开 test，不改变已有签名输入，不把新解释阅读加入原教师 1433 条全文阅读数。实际训练效果仍需实验验证；保留历史 test 暴露、开发题回收训练、教师噪声、单 seed 和解释长度差异披露。
