# 五组、seed42 正式实验修订

2026-10-27，用户最新授权：“那就加上这组，五组吧，目前先这样”。本修订在四组核心实验上加回原 M6，覆盖此前四组及七组的正式组别范围。协议为 `five_groups_seed42_v1`，机器记录为 `output/tgrd_v1/five_group_amendment_v1.json`。

| 当前组 | 内部 ID | 方法 |
|---|---|---|
| G1 | M1 | 普通审核合格 CoT |
| G2 | NLL | 从全部合格步骤独立按 NLL 选位，加入固定优先类型解释 |
| G3 | M3 | NLL＋attention＋masking 联合选位，加入固定优先类型解释 |
| G4 | M7 | 同一联合解释池，经试学后的迁移收益选择解释或原始 CoT |
| G5 | M6 | 原题 CoT 与 Vsel 验证推导交替训练 |

**五组各 seed42 一次、每次 4 epoch，共 5 次正式训练。** 官方 train7473 是候选总数，全文审核后公开合格 N；五组使用相同根题 N、相同每轮根题顺序、初始化和优化设置，每组完整评测官方 test1319。当前不增加其他组或正式训练种子。内部开发试训 701/1701 不改。

## G5 / 原 M6 的执行规则

- 第 1、3 epoch：原题和原始审核合格的教师 CoT。
- 第 2、4 epoch：同一根题 Vsel 冻结顺序中的前两条不同变式，分别配经过验证的推导。顺序不依赖学生表现或公开测试结果。
- 没有合格完整 6 Vsel＋6 Vaudit 探针时，四轮均回退原始 CoT。不能只为这一组删除根题。
- 推导从题目可见的量和审核过的关系模板，经受限的精确有理数运算生成、校验。不得把逆向题中待求量当已知条件；不得直接相信未经核查的教师答案。
- 只有 M6 可以在正式监督中使用 `split=select` 的变式；Vaudit 标签不能进入任何组的梯度。其他四组始终训练原题材料。
- 每个 epoch 每根题一条材料，累积 5 个微批次更新一次；末尾不足 5 条按实际条数平均。各组曝光次数与优化步数一致，监督 token、题目内容和总计算成本分别报告。

G5 训练过的 Vsel 不得用于证明其泛化。开发校准的 Vaudit 仍属于调参数据；确认阶段及最终公开测试按冻结规则使用，不据测试结果选择配置、根题、检查点或种子。

## 研究比较

1. G3−G2：联合选位相对单 NLL 的增量。attention 和 masking 是一起加入的，不能单独认领各自效果。
2. G4−G3：试学和迁移收益引导选择的增量，包括位置/解释类型选择与允许不补充。
3. G4−G1：完整方法相对普通蒸馏的总效果。
4. G4−G5：用变式筛选解释，相比直接用变式训练，是否有更好的最终表现及成本收益。

四项配对比较完整报告效应，并说明相应多重比较校正；题目层面的区间不代替多训练种子稳定性。保留负结果。M2 随机、M4 RSR、M5 LALP 继续移出本轮，因此不宣称优于这些未比较方法。可靠变式当前只覆盖开发 cohort 的 34 个合格根题，不能把已有验证推导称为完成全量材料。

## 实现和状态

`training_plan.py`、`material_builder.py`、正式训练和公开评测校验均使用五组 roster；只有 M6 的第 2、4 epoch 接受两个不同的 Vsel。独立 NLL 仍使用单独诊断和解释池，重合位置/类型复用教师输出；NLL 独有候选不混入 G4 池。

新机器修订覆盖旧组别字段。原教师签名所绑定的运行授权、脚本、数据、500＋40 复用材料不修改。变更前代码和配置保留在 `output/tgrd_v1/protocol_history/before_five_groups_v1/manifest.json`。后台教师继续运行，只有通过质量、开发验证与实际模型工程预检才进入正式训练和公开测试。
