# 本地数学教师运行准备

本次范围：准备并验证本地 Qwen2.5-Math-7B-Instruct 的 4bit MLX 版本。等待用户明确说“运行”后，才加载真实数学教师并生成 5 道自编题。不会由此自动开始学生训练、扩大数据集或租用云机器。

## 固定配置

- 教师来源：`mlx-community/Qwen2.5-Math-7B-Instruct-4bit`，版本 `b144b9b952f8aa481cadb47e2eb6151d18a4de55`；社区从 Qwen 官方数学教师转换，原始权重版本未在社区说明中给出。
- 权重：4bit，group size 64，文件 4,284,346,187 字节；SHA256 `1dce8dc90fe48e6848909373fc8071c6b6505ee716ac28236072dddaf322e9a6`。
- 本机：32GiB 统一内存；复用已有 `.venv-mlx`，不修改旧实验环境或结果。
- 纯文本逐步解答，官方建议 system prompt；greedy，seed 7，每题最多 768 新 tokens，总长度不超过 4096。
- 题目为本次自编的库存、总价、分数、一次方程、矩形五题，不使用 GSM8K/SVAMP 的测试集选参数。
- 学生候选仍为 `Qwen/Qwen2.5-Math-1.5B` Base。本次仅取其分词器/config作映射核查，不加载学生权重。

## 运行前完成

1. 确认无既有训练进程，补齐下载；对全部教师文件核验远端固定版本哈希、大小及 safetensors 索引/边界。
2. 检查分词器模板、assistant边界、题目长度和普通词表映射；特别记录教师/学生输出维数及结束符差异。
3. 用微型随机 Qwen2 的 4bit 版本在 GPU 上测试生成接口、指定序列的 logits 提取、预测位置对齐、浮点有限性和概率归一化。批量与逐 token 预测另作比较：考虑量化 GPU 核差异，logits最大误差要求小于0.01、概率最大误差小于1e-6，且人为错开一 token 后的误差需超过正确对齐误差100倍；此为工程数值检查，不是数学效果指标。
4. 保存 `output/local_math_teacher/preflight.json`。其“就绪”只表示运行前检查通过，不能代替真实教师加载或数学质量测试。

## 用户说“运行”后执行

1. 重新核查文件、环境版本与进程，获取独占锁；只加载一个数学教师。
2. 逐题生成并立即保存原文、结束原因、输出哈希、耗时、token数和速度，不自动重试失败。
3. 对独立小序列 `\boxed{3}` 提取预测每个目标 token 的完整 FP32 logits，验证 T=1/2 时的概率分布。该序列为人为给定目标，不冒充教师自主答对。
4. 保存内存峰值、加载/总耗时及异常。随后全文核查五题的数学推导、答案格式、漂移、截断和矛盾。

## 预期耗时与判断依据

准备工作原估 10–20 分钟，主要不确定项为剩余权重下载。真实教师五题试跑暂估 5–15 分钟，另需约 5–10 分钟全文检查；这些是估计，不是实测。完成首题后才能依据实际速度更新。

可行性通过需要：真实模型能加载、生成原文完整保存、logits有限且对齐正确。五道简单题通过只能说明链路可用，不能用于估计总体准确率或宣布该教师优于学生。

## 后续研究边界

- 4bit教师的概率不等于原始 BF16 教师；若正式研究采用该版本，应在所有相关组固定并披露精度。
- 普通词表相同也不能对不同维数的输出直接做 KL；结束符及新增特殊 token 必须另行明确映射/屏蔽策略。本次只演示共同普通词表上的分布，尚未完成软蒸馏训练。
- 学生 attention 的获取、困难位置选择、各基线及 GSM8K 数据划分是下一阶段，尚未实施或宣布就绪。
- 下载与本地推理不产生模型 API 调用费；有本机资源和电力成本。
- 2026-10-15 的六组实验已完成，原评分、数据、账本及暂停的自动化不变。
