# FYP阶段实验结果与学生模型规模选择

## 1. 当前研究问题

本项目研究不同rationale监督方式对紧凑语言模型数学推理能力的影响，比较answer-only、single-rationale、multi-rationale和diverse multi-rationale四种训练条件。当前实验的主要目的，是判断rationale的数量与多样性是否影响蒸馏效果，而不是预设小模型必须追平教师。

## 2. 当前实验设置

| 项目 | 设置 |
|---|---|
| 教师模型 | DeepSeek-V4-Flash API |
| 学生模型 | Qwen3-0.6B-Base-4bit |
| 微调方式 | MLX QLoRA，rank 16 |
| 独立训练题 | 196道GSM8K题目 |
| 每种条件记录数 | 588条 |
| 随机种子 | 7、17、177 |
| 训练轮数 | 约3 epochs，220次更新 |
| 测试集 | GSM8K 100题、SVAMP 100题 |
| 主要指标 | 最终数值答案Exact Match |

## 3. 主要结果

| 训练条件 | GSM8K EM | SVAMP EM | GSM8K相对Answer-only | SVAMP相对Answer-only |
|---|---:|---:|---:|---:|
| 未微调学生 | 3.0% | 2.0% | - | - |
| Answer-only | 0.7% | 7.0% | - | - |
| Single-rationale | 32.7% | 50.3% | +32.0 | +43.3 |
| Multi-rationale | 32.3% | 47.7% | +31.6 | +40.7 |
| Diverse multi-rationale | **39.3%** | **52.7%** | **+38.6** | **+45.7** |
| 教师模型 | 98.0% | 96.9% | - | - |

SVAMP教师结果96.9%是97次API成功返回中的条件准确率；若将3次超时计为错误，端到端准确率为94.0%。

统计结果显示，GSM8K上diverse multi-rationale比普通multi-rationale高7.0个百分点，95% bootstrap区间为[1.3, 12.7]个百分点；SVAMP上的优势为5.0个百分点，但区间[-1.0, 11.0]跨越0。

## 4. 当前结果说明什么

1. CoT监督明显优于只训练最终答案，两个数据集上的提升都很大。
2. 仅增加rationale数量并不保证提升；普通multi-rationale没有稳定超过single-rationale。
3. 选择差异更大的正确rationale取得最高平均准确率，说明rationale质量和覆盖范围可能比数量更重要。
4. 当前学生仍未接近教师。最佳学生在GSM8K和SVAMP上分别缩小38.2%和53.4%的原始师生差距。
5. 这不是方法失败，而是当前实验同时受到独立训练题少、学生只有0.6B、Base模型起点较弱和QLoRA更新容量有限等约束。

## 5. 学生规模如何选择

模型规模实验需要区分两个目标。

### 科学比较目标

为了研究参数规模是否改变rationale蒸馏收益，应使用同一家族、同一类型的Base模型：

| 规模 | 实验角色 | 是否建议纳入主实验 | 解释 |
|---|---|---:|---|
| Qwen3 0.6B Base | 当前紧凑基线 | 是 | 已完成，可展示低资源条件下的方法差异 |
| Qwen3 1.7B Base | 下一阶段主模型 | **是，优先** | 仍属于紧凑模型，同时显著增加推理容量 |
| Qwen3 4B Base | 规模敏感性实验 | 条件允许时加入 | 用于判断收益是否随学生容量增加而扩大或饱和 |
| 7B数学/推理模型 | 能否接近教师的上界实验 | 不宜混入主对照 | 初始化和训练语料不同，无法只归因于参数规模 |

### 工程目标

如果目标改成尽可能接近教师，而不是严格研究规模效应，可另外使用7B数学专用或推理蒸馏模型。但它应被标为upper-bound experiment，因为它可能在微调前就具有很强的GSM8K能力，不能与0.6B Base的结果直接归因比较。

## 6. 建议的下一阶段

1. 将独立训练题从196道先扩大到约2,000道；预算允许时使用完整GSM8K训练集。
2. 主规模实验使用Qwen3 0.6B Base与1.7B Base；资源允许时加入4B Base。
3. 保持教师、数据划分、rationale选择规则、随机种子和评估提示一致，只改变学生规模。
4. 主比较继续保留answer-only、single-rationale、multi-rationale和diverse multi-rationale。
5. 正式评估使用完整GSM8K测试集和完整SVAMP，而不是各100题。
6. 预先定义“接近教师”为与教师相差不超过5个绝对准确率百分点，并同时报告gap closure。
7. 如果增加7B数学模型，将其作为单独的教师接近性上界，不与同家族Base模型的规模消融混报。

## 7. 向导师汇报时的结论

当前实验已经回答了原始研究问题：CoT监督显著改善0.6B学生，普通增加rationale数量没有稳定收益，而选择更多样的正确rationale取得最佳平均表现。学生尚未接近教师，主要原因不是实验设计错误，而是196道独立训练题和0.6B Base学生不足以承载接近教师的目标。下一步建议优先扩大训练题覆盖，并将1.7B Base作为主学生规模；4B用于规模敏感性，7B数学模型仅作为接近教师的上界实验。
