# 运行与解释记录

本轮按用户授权先看小规模方向，不执行完整多种蒸馏损失和1319题test。前50训练候选按既有冻结顺序选取，审核后48共同有效，不因模型表现换题；100开发题之前已生成并查看部分输出。教师7B社区MLX4bit、学生官方数学1.5B Base BF16，所有调用在本地，无付费API。

位置由未训练学生对教师CoT进行teacher forcing后，按完整等号数学步骤的内容token平均NLL选择。这是对参考轨迹预测困难的代理，不是学生自由生成时的真实出错概率，也不是从固定三位置四采样选择。attention在这版仅为同一位置的教师补充提示标出前文线索，并未改变位置选择器；不能据此声称attention定位比NLL定位更好。

提取使用高NLL内容目标对应的前一预测位置，末4层、所有head及至多8个query平均，再按前文完整单位的内容token平均权重排名。50题均核验前后logits差0、未来权重0、归一化误差<1e-5。候选只包含等号数学步骤，不能解决任意自然语言推理步骤分段。部分选择仅为已知量复述，部分attention线索遗漏条件甚至关联不对，原样保留并在location_reviews披露。

教师局部提示初版不遵守JSON和局部任务，转为引用所选步骤的续写；共同插入桥接语加生成首个完整句。v3流式句号误把小数前缀当句尾，最终v4要求句号后真实空白或完整EOS。版本、原生成及探针均保存，不挑最有利答案。初版最终实际保存5条（发出停止时仍可能多完成一条），v3两组各50条均已完成，不能说v3已被终止。v3探针3条在only队列精确复用，计调用不重复。

材料新生成保存记录合计261次，20,275生成tokens，累计记录生成819.787秒：50原CoT、5初版、3+3+3提示探针、v3 only额外47与attention50、v4两组100。不包含模型加载、被中断但未保存的工作、定位和逐条人工审核，不代表全部墙钟耗时。最终监督仅使用48原CoT及两组各48v4解释，其余留档。

三组独立从原模型初始化相同LoRA，均4轮192微步40更新，目标只监督completion和学生EOS，无prompt或padding目标。各组一遍监督tokens12934/14397/14385，最长完整序列730。CPU随机小模型检查损失与稠密实现差0、LoRA梯度及更新非零、保存重载logits差0；真实adapter与第一轮存在参数变化，完成metadata和校验hash留档。

两个补充组监督token总量相近，但48对解释有15对完全相同，4对长度差>16tokens，最大40。并且attention提示只是额外强调教师已经可见的部分前文。本轮无随机证据、额外提示长度和完整预算对照，不能分离注意力排序、重复强调、长度和措辞效应。

冻结v1与训练前签名的v2同时报告，不用训练后结果改解析器。v2是在开发样例设计的敏感性检查，不是独立测试。原gold问题、单位等价和模拟代码错误由辅助实审单列，保持所有组主数字分不改。最终未训练学生及三组训练后共400输出全文辅助审核全部完成，完整性审计通过；本次助手复核不是独立盲评或形式证明。
